# RAW NEWS PIPELINE

## 1. Ingest (приём данных)
    - Получить новые сообщения из источников
    - Добавить как raw_news (избегая дублей по external_id)

## 2. Обработка raw_news
    - Оценить важность (importance)
    - Проставить теги (tags)
    - Сделать суммаризацию (summary)
    - Посчитать вероятную interest_score_for_user
    - Сделать векторизацию (embedding)

## 3. Работа с векторами
    - Найти похожие raw_news (по embedding)
    - Объединить похожие raw_news в группы (кластеризация)


# NEWS EVENT PIPELINE (агрегированная новость)
 
## 4. Формирование итоговой новости
    - Создать NewsEvent из кластера raw_news
    - Суммаризировать агрегированную новость (если нужно)
    - Проставить финальные темы/теги/важность
    - Подготовить финальный текст для пользователя

## 5. Отправление пользователю
    - Отобрать новости, подходящие пользователю
    - Отправить финальную подборку пользователю
